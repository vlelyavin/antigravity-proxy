# antigravity-proxy

[English README](README.md)

Если у вас есть подписка Google AI Pro, а рабочим инструментам нужен OpenAI-совместимый эндпоинт, этот проект решает задачу. Локальный релей транслирует запросы OpenAI chat completions через OAuth от Antigravity / Code Assist, позволяя Hermes, OpenCode и любым другим совместимым клиентам работать по подписке вместо поминутной оплаты API.

## Что делает

- Перечитывает локальный OAuth-токен Antigravity/Gemini с диска на каждый запрос, поэтому свежая авторизация подхватывается на лету без перезапуска.
- Структурно транслирует данные между OpenAI `chat/completions` и Cloud Code `generateContent` в обе стороны, включая вызовы инструментов (tool calls) и изображения.
- Поддерживает стриминг: преобразует SSE-фреймы Cloud Code в формат OpenAI SSE.
- Балансирует нагрузку по нескольким аккаунтам через round-robin с кулдауном при 429: достаточно положить несколько файлов с токенами, и прокси будет их ротировать.
- Автоматически повторяет запросы с экспоненциальным бэкоффом при ошибках 5xx и сбоях сети; исчерпание квоты не роняет запрос, а переключает его на следующий аккаунт.
- Поддерживает опциональный API-ключ, чтобы закрыть эндпоинт от нежелательного доступа из локальной сети.
- Ноль внешних зависимостей - используется только стандартная библиотека Node.js.

## Чем не является

- Не является продуктом Google и никак с компанией не связан.
- Не хостится вовне: работает исключительно на вашей машине с вашими учетными данными.
- Не распространяет готовые учетные данные: в репозитории нет никаких секретов.

## Честно

Прокси использует подписочный OAuth вне официального клиента. Это серая зона Google ToS - как и у любых других Code Assist прокси. При слишком агрессивном использовании можно потерять подписку. Квота выделяется на пользователя (около 1500 запросов в день на AI Pro), при этом один сложный агентский промпт может генерировать сразу несколько запросов. Используйте на свой страх и риск.

## Требования

- Node.js 20+ (без сборки и без `npm install`)
- Локальный OAuth-токен из любого удобного источника:
  - **antigravity cli** (`agy`) → `~/.gemini/antigravity-cli/antigravity-oauth-token`
  - **gemini cli** (`npm i -g @google/gemini-cli && gemini`) → `~/.gemini/oauth_creds.json`
  - Любой JSON-файл вида `{access_token, refresh_token, project_id?}` в каталоге `~/.antigravity-proxy/accounts/*.json`

## Запуск

```bash
git clone https://github.com/vlelyavin/antigravity-proxy.git
cd antigravity-proxy
node src/cli.js
```

Сервер слушает адрес `127.0.0.1:8317`.

Проверить статус:

```bash
curl -sS http://127.0.0.1:8317/health
```

Эндпоинт `/health` покажет все обнаруженные аккаунты и время жизни токенов. После этого можно отправить тестовый запрос:

```bash
curl -sS http://127.0.0.1:8317/v1/chat/completions \
  -H 'content-type: application/json' \
  --data '{"model":"gemini-3.8-flash-high","messages":[{"role":"user","content":"reply with exactly: pong"}]}'
```

Ответ `pong` означает, что цепочка полностью настроена и работает.

## Подключение к инструментам

Укажите OpenAI-совместимый базовый URL `http://127.0.0.1:8317/v1` и API-ключ (заданный в конфигурации или просто `none`).

Пример для OpenCode:

```jsonc
// ~/.config/opencode/opencode.jsonc
{
  "provider": {
    "antigravity": {
      "npm": "@ai-sdk/openai-compatible",
      "options": { "baseURL": "http://127.0.0.1:8317/v1", "apiKey": "none" },
      "models": {
        "gemini-3.8-flash-high": { "limit": { "context": 1048576, "output": 65536 } },
        "gemini-3.1-pro-high": { "limit": { "context": 1048576, "output": 65536 } }
      }
    }
  }
}
```

Для Hermes и любых других OpenAI SDK: `base_url=http://127.0.0.1:8317/v1`, `api_key=none`, а идентификаторы моделей можно получить через `GET /v1/models`.

## Модели

Поддерживаются `gemini-3.8-flash-{low,medium,high}`, `gemini-3.7/3.6-flash-*`, `gemini-3-flash`, `gemini-3.1-pro-{low,high}`, `claude-sonnet-4-6`, `claude-opus-4-6-thinking`, `gpt-oss-120b-medium`. Полный список находится в `src/rewrite/openai-translate.js` - его можно дополнять по мере появления новых моделей у Google.

## Мультиаккаунт

Чтобы подключить несколько аккаунтов, добавьте дополнительные файлы токенов в `~/.antigravity-proxy/accounts/*.json` (формат: `{access_token, refresh_token, project_id?, email?}`). Ротация выполняется по round-robin среди работоспособных аккаунтов. При получении 429 аккаунт временно уходит в cooldown, а запрос автоматически перенаправляется на следующий. 2-3 аккаунта на один резидентский исходящий IP - разумный максимум: большая нагрузка похожа на ферму, а фермы Google встречает капчей.

Запросы без стриминга идут к апстриму по потоковому эндпоинту и собираются обратно в один JSON-ответ: обычный вызов ждет ответ целиком и на длинных текстах выходит за любой разумный дедлайн, тогда как поток отдает первый токен за секунды. У каждой попытки остается свой бюджет из `rotation.attemptTimeoutsMs` (в поставляемом конфиге 90, 90, 60, 60, 45, 45, 45 секунд, последнее значение повторяется), поэтому зависший аккаунт пропускается, а не держит клиента. Клиент может задать свою лестницу заголовком `x-attempt-timeouts-ms` (например, `45000,30000`) на не-стриминговых запросах.

## systemd

```bash
sudo ./scripts/install-systemd.sh
```

Скрипт создаст юнит, добавит его в автозагрузку и запустит сервис. Инструкции по ручной настройке описаны в `docs/systemd.md`.

## Структура

```
src/
  config/         дефолты, env-оверрайды, лоадер
  credentials/    поиск токен-файлов (agy / gemini-cli / raw), oauth refresh
  rewrite/        openai <-> cloud code трансформы + каталог моделей
  upstream/       клиент cloud code с ретраями, пул аккаунтов с cooldown
  server/         http: /health, /v1/models, /v1/chat/completions
test/             22 теста, без сети
```

## Безопасность

- Оставляйте привязку только к `localhost`, если нет осознанной необходимости открывать доступ наружу.
- Никогда не коммитьте файлы токенов и `config.json`.
- Задайте `apiKey` в `config.json`, если к порту возможен доступ из локальной сети.
